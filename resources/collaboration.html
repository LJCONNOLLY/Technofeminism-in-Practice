Collaboration Tools

This course uses several collaborative platforms to support asynchronous learning, peer engagement, and multimodal reflection.

Weekly Reflections: Padlet

Each week has a dedicated Padlet board for sharing reflections, questions, and connections.

How to use:

  • Post text, images, links, or audio
  • Comment on peers' posts
  • Use #tags to organize thoughts

Example Padlet link: padlet.com/techfem/week-X

🗺️ Concept Mapping: Miro

Interactive whiteboard for visualizing connections between concepts, theorists, and case studies.

Uses:

  • Map relationships between theorists and ideas
  • Visualize platform infrastructures
  • Brainstorm design interventions

Multimodal Reflections: Google Forms

Submit audio, video, or zine reflections via Google Forms with Drive integration.

Supported formats:

  • Audio files (MP3, M4A, WAV)
  • Video files (MP4, MOV)
  • PDFs (for digital zines)
  • Image files (PNG, JPG)

Setup Instructions for Instructors

  1. Padlet: Create boards for each week. Set privacy to "Anyone with link can view and post."
  2. Google Docs: Create shared docs with commenting enabled. Share links in course pages.
  3. Miro: Create board, add students as collaborators or use public link.
  4. Google Forms: Create form with file upload field connected to Google Drive folder.
