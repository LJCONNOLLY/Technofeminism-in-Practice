Collaboration Tools

This course uses several collaborative platforms to support asynchronous learning, peer engagement, and reflection—whichever Signature Project track you're on.

Weekly Reflections: Padlet

Each week has a dedicated Padlet board for sharing reflections, questions, and connections.

How to use:

  • Post text, images, links, or audio
  • Comment on peers' posts
  • Use #tags to organize thoughts

Access the Padlet

Shared Research Notes: Google Docs

Shared Google Docs for collaborative research and case-study notes across both tracks.

Documents include:

  • Shared research resources
  • Collaborative literature notes
  • Track A/B project-in-progress notes

Access: Links provided in weekly modules

🗺️ Concept Mapping: Miro

Interactive whiteboard for visualizing connections between concepts, theorists, and case studies.

Uses:

  • Map relationships between theorists and ideas
  • Visualize platform infrastructures
  • Brainstorm design interventions

Access Miro Board

Submitting Work: Google Forms

Submit reading responses, proposals, and final projects via Google Forms with Drive integration.

Supported formats:

  • Written documents (PDF, DOCX)
  • Track B prototype links (GitHub repo, deployed URL)
  • Presentation slides
