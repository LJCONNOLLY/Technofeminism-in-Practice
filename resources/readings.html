Software & Subscriptions

A laptop able to run a modern browser and a Node.js development environment. A free GitHub account, for Track B prototype hosting and version control. Claude Pro subscription (approx. $20/month, one semester). Required for students pursuing Track B, since it provides access to Claude Code. Not required for Track A, though free-tier access is sufficient for anyone who wants to use AI tools for research or drafting. If cost is a barrier, contact the instructor before the proposal deadline so we can look at department license options.
